# 🎮 Xbox Game Pass - Dashboard

## 📌 Sobre o projeto

Este projeto consiste em um dashboard desenvolvido no Microsoft Excel para análise de dados relacionados às assinaturas do Xbox Game Pass.

A partir de uma base de dados de assinantes, foram organizadas e analisadas informações como planos de assinatura, valores, renovação automática, serviços adicionais e descontos, transformando os dados em indicadores e informações visuais.

## 🎯 Objetivo

O objetivo do projeto é utilizar o Microsoft Excel para organizar, analisar e visualizar dados relacionados às assinaturas do Xbox Game Pass.

A análise busca responder questões relacionadas a:

- Faturamento das assinaturas;
- Planos contratados;
- Renovação automática;
- Tipos de assinatura;
- Serviços adicionais;
- Aplicação de cupons e descontos;
- Comportamento das vendas.

## 📊 Dashboard

O resultado das análises foi apresentado por meio de um dashboard, facilitando a visualização dos principais indicadores e informações da base de dados.



## 🧮 Análise e cálculos

Além da parte visual, o projeto possui uma área dedicada aos cálculos e às perguntas de negócio utilizadas para analisar os dados.

Os cálculos servem como base para a construção dos indicadores apresentados no dashboard.

## 📂 Estrutura do projeto

Área destinada à apresentação visual dos principais indicadores e resultados da análise.

### 🗃️ Bases

### 🧮 Cálculos
